# VenueCMS template-agency no.2

This is a starter template for [Venue CMS](https://venuecms.com).

It is built with Next.js and uses the [Venue SDK](https://venue.gitbook.io/docs/sdk) to connect to your VenueCMS instance.
This is one of the templates we use for rendering sites when users choose to host via Venue but can also be used as a template for building your own site using the SDK.

This is not currently ready for production.

Note: You will need an API key to work on this template locally.

## Getting Started

First, install your dependencies:

```
pnpm install
```

Then run the development server:

```bash
pnpm run dev
```

To see the result open [http://[siteKey].localhost:3000](http://[sitekey].localhost:3000) with your browser replacing [SiteKey] with the key for the instance you wish to pull data from.
